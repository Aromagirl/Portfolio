## Screen Structure & Game Systems

Screen diagrams describe the organisation of controls, game information and available actions. These documents help game designers and developers agree on how features fit into the interface before visual implementation.

## Interaction States

State diagrams describe how controls and objects respond to user input. They provide developers and QA with a shared reference for behaviour and help identify the visual assets needed for each state.

## Instructions for Artists & Developers

Visual instructions connect cursor states, object highlights and character responses to player actions. They clarify which graphics the art team needs to supply and how those assets should behave in the implementation.
