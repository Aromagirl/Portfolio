## About i-Jet Media & my role

<div class="tickeron-ui-intro">
<div class="tickeron-ui-description">
<p>i-Jet Media published and distributed social games developed for short sessions, ongoing progression and interaction between players.</p>
<p>This work explored separate mobile interfaces for existing social games. The examples adapt dense desktop scenes into compact browser screens with lists, menus and focused actions, rather than simply scaling down the desktop layout.</p>
</div>
<section class="tickeron-ui-responsibilities" aria-labelledby="ijet-role">
<h3 id="ijet-role">My role as Lead UX Designer:</h3>
<ul><li>&#128241; Adapting desktop game interactions for mobile</li><li>&#128161; Designing compact navigation and action flows</li><li>&#128279; Prototyping interface solutions</li><li>&#129309; Collaborating with developers and checking implementation</li></ul>
</section>
</div>
